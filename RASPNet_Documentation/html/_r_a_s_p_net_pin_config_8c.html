Setup I/O pins of the ATMEGA328p.

Further Details

  • PB0: LED Indicator for Clock -> OUTPUT
  • PB4: Clock send -> OUTPUT
  • PB5: Data send -> OUTPUT
  • PD4: Clock receive -> INPUT
  • PD5: Data receive -> INPUT
  • Enable interrupt for Clock receive PD4
    • PD4->PCINT20
    • PCINT20->PCMSK2
    • PCMSK2-> PCICR->PCIE2
